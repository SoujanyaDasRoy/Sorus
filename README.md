# Sorus

Sorus is a free, open-source app that takes over the sound of a whole device — every song, video and movie — and runs it through a professional-grade audio chain: preamp, a very advanced EQ, dynamics, bass, stereo/spatial effects and a safety limiter. It ships for Android and Windows, sharing one native C++ DSP engine.
